# Gerenciador de Tarefas para Estudantes

Protótipo de sistema desenvolvido para auxiliar estudantes na organização de tarefas, matérias e compromissos acadêmicos.

## 💻 Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 🎯 Objetivo

Facilitar o gerenciamento das atividades acadêmicas de forma simples e organizada.
